# SHIELD

Reporting program for [Mississippi State University](https://msstate.edu)'s Cybersecurity Assessment Program meant to replace [CSET](https://github.com/cisagov/cset).  

### Supported Assessments

- [CISA, CPG 2.0](https://www.cisa.gov/cybersecurity-performance-goals-2-0-cpg-2-0)

More to come.

### Personalization

Upload your brand images to `public/images` or another public location and then update the URLs and colors inside of `branding.json`.
